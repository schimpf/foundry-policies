How to Read a PDF in a Dyslexia-Friendly Font on Android

A PDF fixes the font, the size and the spacing on the page. You cannot make the letters wider or change the font. The fix is to pull the text out of the PDF and show it as a normal book. This page explains how that works and where it fails.

Why PDFs are hard to read

  • The layout is fixed, so text size changes mean pinching and side scrolling.
  • Lines are often long and tightly spaced.
  • The font is whatever the author chose.
  • Columns and footnotes break the reading order for a screen reader or read-aloud tool.

Reflowing means the text is rewrapped to your screen with your own font and spacing.

First check: does the PDF contain text?

  1. Open the PDF in any viewer.
  2. Try to select a word with a long press.
  3. If you can select and copy words, it has text. It can be reflowed.
  4. If the whole page selects as one image, it is a scan. It has no text to extract.

Scanned PDFs need OCR (text recognition) first. Dyslexia Reader Android does not do OCR, so scanned PDFs without text are not supported.

Steps in Dyslexia Reader Android

  1. Open the app and go to the Library.
  2. Choose to import a book and pick your PDF from the device.
  3. Check the import screen. It shows the size of the text and the reading time.
  4. Open the book. Your font and spacing now apply.
  5. Open the Appearance panel to set the font, text size and spacing.

PDF import is one of the features that unlock with the one-time purchase. TXT and EPUB import work without it.

Limits

The app refuses files outside these limits and tells you why.

  • File size up to 100 MB.
  • Up to 3,000 pages.
  • Up to 5,000,000 characters of text.
  • A PDF locked with a password cannot be opened. One with no open password works normally.
  • A damaged file is reported as corrupt.

Tips for better results

  • Use PDFs exported from a word processor or a website. These keep clean text.
  • Two-column papers can mix columns. If the order looks wrong, look for an EPUB or text version of the same document.
  • Headers and footers on every page may repeat in the text. Skim past them or read with the ruler on.
  • For long documents, use read aloud with sentence highlight to follow along. It uses the voice installed on your device and works offline.

If the import fails

  • Too large: the file, page count or text is over a limit above. Split the PDF into parts with a PDF tool and import each part.
  • Password: remove the password in a PDF tool, then import again.
  • Scanned: the PDF has no text. Run OCR on a computer first, or look for a text version from the source.
  • Corrupt: download the file again, or open and re-save it in a PDF viewer.

Check the result before you read

Open the first pages and look at three things. Are paragraphs in the right order? Are words split by odd line breaks? Is there repeated header text? If the text looks clean, set your font and spacing and start reading. If not, try another copy of the document.

Other ways to get text in

  • Share plain text from another app into the library.
  • Import a TXT file.
  • Import an EPUB. This keeps chapters and works well for books.

About the app

Dyslexia Reader Android is an offline reader for dyslexic readers, with dyslexia-friendly fonts, a line focus ruler, spacing sliders and read aloud.

  • No account is needed.
  • Books and settings stay on your device. The app has no internet permission.
  • You can delete one book or all app data in Settings.

How to Do a Time Study Step by Step

A time study measures how long a task takes by timing it with a stopwatch, element by element, over several cycles. This guide shows the steps in order, from choosing the task to calculating the standard time. It follows the method described in standard work-measurement texts such as Niebel and Freivalds, *Methods, Standards, and Work Design* (McGraw-Hill, 12th edition, 2009), and the International Labour Office, *Introduction to Work Study* (4th edition, 1992).

Before you start

  • Fix the method first. Time a task only after the method, tools and layout are settled. Timing a method that is about to change wastes the study.
  • Tell the operator. Explain what you are doing and why. Choose a worker who is trained and works at a typical pace.
  • Pick a spot where you can see the hands and the work without being in the way.

Step 1: Break the task into elements

An element is a short, clearly defined part of the task with a start and an end point you can see or hear.

Good element rules:

  • Keep each element long enough to time reliably. Very short elements are hard to catch with a tap.
  • Pick end points that are easy to spot, such as "part released" or "box closed".
  • Keep machine time and manual time in separate elements.
  • Write the list in the order the work happens.

Example for packing an order: 1. Pick item, 2. Place in box, 3. Seal and label.

Step 2: Time several cycles

A cycle is one full run through all elements. Start the timer, then record the end of each element as it happens.

  1. Start the first cycle.
  2. At the end of each element, press lap. The time for that element is stored and the next one starts.
  3. After the last element, the next lap starts the following cycle.
  4. Repeat for the number of cycles you need.

If you make a wrong tap, correct that one reading instead of starting over. Note any interruption or unusual event so you can discard that reading.

How many cycles?

There is no single number that fits every task. A common rule is to take more cycles when the task is short, when the readings vary a lot, or when many workers will use the standard. Read the spread of the readings: if the standard deviation is large compared with the average, take more cycles or check whether the elements are defined well. Texts such as Niebel and Freivalds give statistical methods to work out the number of observations for a chosen confidence level.

Step 3: Rate the pace

While you time each element, judge the pace of the operator against a normal pace. Write it as a percent:

  • 100% is normal pace.
  • 120% is clearly faster than normal.
  • 80% is clearly slower than normal.

The rating is a judgment, so rate each observation as you see it and be consistent from one study to the next.

Step 4: Calculate normal time

For each observation, multiply the observed time by the rating and divide by 100. Average these results for each element, then add up the elements.

  • Normal time = observed time × rating ÷ 100

Example: 22 s observed at 110% gives 24.2 s of normal time.

Step 5: Add the allowance

Workers need time for personal needs, fatigue and delays (PF&D). Add this as an allowance percent on top of the normal time.

  • Standard time = normal time × (1 + allowance ÷ 100)

With a 15% allowance, a normal cycle of 60 s becomes 69 s. The size of the allowance depends on the work and on your company's policy. The ILO book above has tables for relaxation allowances.

Step 6: Check and report

  • Compare the minimum and maximum of each element with its average. A single far outlier is usually an interruption.
  • Look at the cycle totals. If they drift up or down, the operator may be learning or tiring.
  • Export the readings and share them with the team, so the standard can be checked.

Tinag2 Privacy Policy

Effective: 2026-11-13
App: Tinag2 (package es.schimpf.tinag2)
Developer: Gerrit Schimpf
Contact: apps@schimpf.es

Summary

Tinag2 is a client for your own Icinga 2 and Nagios/Naemon (Thruk) monitoring servers. The developer runs no server for this app, has no accounts, and receives no data from it. The app contains no advertising, no analytics and no crash reporting.

What the app connects to

The app connects only to the monitoring servers you enter yourself. It sends requests to read host and service states, and, when you ask for it, to acknowledge a problem, schedule a recheck or set a downtime. It sends your server user name and password to that server using HTTP basic authentication. No other network connections are made by the app.

The app allows plain http:// addresses because many monitoring servers sit on a local network. If you enter one, the app warns you that the password is then sent unencrypted. Use https:// when you can. Optionally you can pin the SHA-256 fingerprint of a server's certificate, for self-signed servers.

What is stored on your device

  • Your server entries: name, type, address, user name, optional certificate fingerprint. The password is encrypted with a key held in the Android Keystore.
  • Your alert settings, and a list of problems you were already notified about.
  • The latest problem list fetched from each server, kept so the app can show it when a server cannot be reached.

This data stays on your device. Android backup is turned off for the app, so it is not copied to Google Drive or another device. Uninstalling the app or clearing its storage deletes all of it. You can also delete a server entry in the Instances screen.

Permissions

  • Internet: to reach the servers you configure.
  • Notifications: to alert you about new or worse problems. You can deny it; the app then works without alerts.

Background libraries used by the app (for example the Android work scheduler that runs the sync every 15 minutes) may add system permissions such as checking the network state. They are not used to collect personal data.

Sharing

The developer shares nothing, because the developer receives nothing. Data sent to your monitoring server is handled by whoever runs that server; check their policy. Host names, service names and check output shown in the app come from your server.

Children

The app is a tool for system administrators and is not directed at children.
